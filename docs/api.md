# blue-data-planner REST API

**Not built, and not in the first release.** `platform/api/` does not exist, and no package in the
repository declares a web framework
([`design/03-high-level-architecture.md`](../design/03-high-level-architecture.md)).

A REST API would map to the same two library operations every other interface uses, so its
endpoints get specified when someone builds it. See
[`design/09-api-interface-spec.md`](../design/09-api-interface-spec.md#4-rest-api).

Use the [Python library](api-reference.md), the [`blue-planner` CLI](cli.md), or the
[MCP server](mcp.md) instead.
